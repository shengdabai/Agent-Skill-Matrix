# Agent Skill 产品矩阵 · 10 原型设计与评分对比

> 方法论来源:《图解 Skill：AI 提效实战指南》(宝玉)
> 产品形态:Agent Skill 包(符合 Agent Skills 开放标准,可上架扣子 / ClawHub / GitHub 技能市场)
> 设计原则:① 一个技能只做一件事(书 5.1)② 三种类型——约束型/模板型/流程型(书 4.3.5)③ 技能给经验而非工具能力(书 3.4.3)④ 从真实高频痛点长出来(书 6.1.1)

## 一、10 个原型设计

## 二、评分 Rubric(7 维 × 10 分 = 70 满分)

维度直接对应书中判断框架:

| 维度 | 出处 | 说明 |
|---|---|---|
| D1 高频复用 | 3.2.1 问题一「会反复做吗」 | 用户多久用一次,频次越高分越高 |
| D2 一致性需求 | 3.2.1 问题二「对一致性有要求吗」 | 越需要稳定输出越适合技能 |
| D3 流程成熟可固化 | 3.2.1 问题三「流程稳定吗」 | 流程越清晰、越能写成 SOP 分越高 |
| D4 经验壁垒/差异化 | 3.4.3「工具给能力,技能给经验」 | 是否承载真经验、市场是否同质化 |
| D5 可实现性 | 第 7 章工程可行性 | 用现有工具/脚本能否稳定做出来 |
| D6 商业化潜力 | 6.5.3 社区发布/上架盈利 | 付费意愿 × 市场规模 |
| D7 合规/安全(反向) | 3.5 安全是头等大事 | 法律/隐私风险越低分越高 |

## 四、评分解读(为何这 3 个胜出)

### 🥇 P01 小红书爆款文案(64)
- **D1=10 / D6=10**:小红书是中文内容第一战场,日活创作者海量,"去 AI 味种草文"是扣子市场最高频付费需求之一。
- **D4=8**:同质化的"去 AI 味提示词"满天飞,但把「爆款公式 + 个人语气库 + 禁止清单」固化成可迭代技能,正是书 4.1 的核心壁垒。
- 风险点:平台违禁词需内置过滤(已计入设计)。

### 🥈 P08 数据分析报告(62)
- **书第 7 章的"衣钵"**:V1→V3 完整迭代路径现成,工程方法最成熟。
- **D4=9 / D6=9**:能交付"发给老板的 HTML 报告",B 端付费意愿强,且大模型裸跑只会算术、技能价值一目了然(书 7 章对比测试)。
- 直接复用书中三阶段分析法 + so-what 哲学 + 报告模板 + 设计简报。

### 🥉 P02 简历 STAR 优化(61)
- **D2=9 / D5=10**:流程极成熟(STAR 拆解是公认方法),纯文本可实现,零外部依赖。
- **D6=9**:求职者付费意愿在所有场景里最高(关乎 offer),海外 Rezi/Teal 已验证市场。
- **D7=9**:不碰隐私存储,仅本地处理。

### 为何淘汰其余
- P04 周报:频次最高但 **D4=5**(书已给基线、市场免费替代多,差异化弱)、D6=6,商业天花板低。
- P03 合同 / P10 法律:D7 合规风险高(易被当法律建议),且 P03 频次低(D1=5)。
- P05 信息图:依赖出图工具(D5=7),发布后他人环境可能无生图 API(书 6.1 朋友 B 的坑)。
- P09 论文润色:频次偏低 + 学术诚信争议(D7=7)。
- P06 / P07:均衡但无单项突出,被前 3 名压制。

## 五、最终选定(进入全链路开发)

| 序号 | 技能 | 类型 | 上架去向 | 变现方式 |
|---|---|---|---|---|
| **products/01** | `xhs-hit-copywriter` 小红书爆款文案 | 约束 + 模板 | 扣子技能商店 / ClawHub | 商店付费技能 / 引流私域 |
| **products/02** | `data-report-pro` 数据分析报告 | 流程(V1→V3) | ClawHub / GitHub | B 端订阅 / 企业内部市场 |
| **products/03** | `resume-star-optimizer` 简历 STAR 优化 | 流程 + 约束 | 扣子 / ClawHub | 商店付费 / 单次润色付费 |

下一步:按书第 6 章工程流程(需求→设计→实现→测试→发布)全链路开发,每个产出可上架的完整技能包。
