# 领域基准参考（可选加载）

> **何时加载本文件**：当待分析数据明显属于"电商/投放/运营"领域，且你需要给指标找"健康线/盈亏线/预警线"作为对比参照系时（呼应分析哲学第 1 条"对比产生意义"）。
> **何时不加载**：数据是通用业务数据（财务、人力、问卷等）且用户没有给出基准——这时**不要套用下面的数字**，而应以"整体均值 / 上期 / 用户给的目标"作为参照，并在报告中说明参照来源。

## 重要免责

下列数字是**行业经验区间的示例**，并非铁律。不同品类、客单价、利润结构差异巨大。使用时：
- 优先用**用户自己提供的基准**（公司目标、历史水平）
- 没有时才用下面的经验值，且必须在报告中标注"以下采用行业经验线，实际请以贵方业务为准"
- 切忌把经验线当作绝对真理去下判断

## 投放 / 广告

| 指标 | 经验参照 | 含义 |
|------|---------|------|
| ROI / ROAS | 盈亏线常在 1.5~2.5，视毛利率而定 | ROI < 盈亏线 = 该投放在亏钱 |
| ROI 健康线 | 通常 ≥ 3 视为优质渠道 | 有放量空间 |
| CTR（点击率） | 信息流 1%~3%，搜索更高 | 低于区间下限 = 创意/定向有问题 |
| CPA（获客成本） | 应 < 客单价 × 毛利率 | 高于此线则单均亏损 |
| 创意疲劳信号 | 同素材 CTR 连续下滑 / 频次过高 | 需换创意 |

## 电商 / 销售

| 指标 | 经验参照 | 含义 |
|------|---------|------|
| 退货率 | 服饰常见 10%~20%，标品个位数；预警线常设 12%~15% | 超预警线侵蚀利润，需归因 |
| 复购率 | 视品类，30 天复购 15%+ 较健康 | 偏低 = 留存问题 |
| 转化率 | 站内 1%~3% 常见 | 低于区间 = 承接/信任问题 |
| 客单价 | 与品类强相关 | 看趋势比看绝对值有意义 |
| 毛利率 | 决定上面所有盈亏线 | 是判断 ROI 是否健康的根基 |

## 用法示例

> 单看"退货率 18%"无意义；加载本文件后可写成：
> "退货率 18%，高于行业预警线（约 12%~15%），且高于本期整体均值 14%，是侵蚀利润的关键风险——建议对该板块做退货原因归因。"

这就是"对比产生意义 + 回答 So What"的落地。
