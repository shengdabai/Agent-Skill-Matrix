# data-report-pro · 数据分析报告技能

> 把一份杂乱的 Excel/CSV，变成一份**有结论、有图表、有建议**的专业 HTML 分析报告。

**版本**：v3.0.0
**类型**：流程型 Agent Skill
**方法论来源**：《图解 Skill：AI 提效实战指南》(宝玉) 第 7 章

---

## 它解决什么问题

普通 AI 拿到表格只会"罗列数字、堆一堆图"。本技能固化了一套资深分析师的工作流，让产出从"报表"升级成"洞察"：

```
上传 Excel/CSV → 三阶段专业分析 → 生成文本与表格可离线查看的 HTML 报告
```

三阶段分析法：
1. **理解结构** —— 一行代表什么？哪些是维度、哪些是指标？有没有时间列？
2. **统计概况** —— 均值+中位数、分位数、零值/缺失，看清数据真实形状。
3. **挖掘发现** —— 异常检测（2σ）、相关性（|r|>0.7）、趋势，产出真正的洞察。

配套五条分析哲学（对比产生意义 / 回答 So What / 标题就是结论 / 异常值是金矿 / 警惕虚假精确）贯穿始终。

## 使用示例

```
你：帮我分析下这份投放数据，出个报告
   （附 campaign-data-sample.csv）

技能：
  1. 探查文件 → 识别编码、表头、维度/指标、时间列
  2. 三阶段分析 → 发现"信息流 ROI 低于示例参考线""整体 ROI 逐月下降""预算错配"
  3. 生成 report-20260606.html → 一句话摘要 + KPI 卡 + 4 张图 + 建议 + 明细表
  4. 报告路径已生成，双击可查看文本与表格；图表需联网
```

`sample/campaign-data-sample.csv` 是一份内置测试数据（28 行投放记录，含低 ROI 渠道、逐月 ROI 下降和缺失退货率），可直接用来体验。6 月只记录到 13 日；月度 GMV 在 4 月、5 月分别为 201,905、215,210 元，并非逐月下降。示例盈亏线 2.0 是假设参照，实际盈亏需结合业务成本核对。

## 依赖与兼容性

- **分析侧**：Python + `pandas`（读取与统计）。Excel 需 `openpyxl`。
- **报告侧**：HTML 内嵌 `Chart.js@4`（从 jsDelivr CDN 加载）。
  - 图表需要联网加载 Chart.js，不保证浏览器缓存可用；离线时只显示文本、表格与明确提示。
  - 如需**完全离线**，把 `chart.umd.min.js` 内容内联进 `<script>` 标签即可。
- **数据内嵌**：报告数据以 `report-data` JSON 数据块 写入 HTML，**不依赖本地文件 fetch**，因此双击即可打开，不会触发 CORS。
- 兼容主流浏览器（Chrome / Edge / Safari / Firefox），响应式适配手机。

## 卖点：V1 → V3 的演进

本技能不是一次写成，而是按书中方法论迭代到生产级——这正是它专业的来源：

- **V1（能跑）**：把"读 CSV → 算几个统计量 → 画几张图"固化下来。问题：图表堆砌、没有结论、平均值被极端值误导。
- **V2（有方法）**：引入三阶段分析法和五条分析哲学，强制"每个发现都要 So What、标题就是结论、数字要有对比参照"。报告从"罗列"变"洞察"。
- **V3（生产级 · 当前）**：
  - 拆分 references（SKILL.md 克制、模板/简报/领域知识按需加载，省上下文）
  - 完整可用的杂志风 HTML 模板（KPI 卡 + 发现卡 + 图表 + 明细表，文本与表格可离线，图表需联网）
  - 设计简报 + 领域基准 + 踩坑点 + 安全规范
  - 7 用例评测题库（含反向触发用例，避免对简单查数过度反应）

这套"V1 能跑 → V2 有方法 → V3 生产级"的打磨过程，本身就是技能质量的保证。
