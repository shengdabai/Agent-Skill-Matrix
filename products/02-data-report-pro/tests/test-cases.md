# data-report-pro 评测题库

每个用例含：**真人指令** + **输入** + **期望行为** + **客观检查项**。客观检查项用于人工/自动判定是否合格。

---

## 用例 1（主流程 · 正例）

- **真人指令**：「帮我分析下这份投放数据，出个报告」
- **输入**：`sample/campaign-data-sample.csv`
- **期望**：
  - 走完三阶段：识别"一行=一次投放，维度=板块/渠道/日期，指标=消耗/GMV/ROI/退货率"；统计概况给出均值+中位数；挖掘出"信息流 ROI 低于示例参考线""整体 ROI 逐月下降""预算错配"等发现。
  - 生成单文件 HTML 报告，含一句话摘要、KPI 卡片、3-5 条结论式标题的发现、关注项、建议、明细表。
- **客观检查项**：
  - [ ] 产出一个可双击打开的 `.html` 文件（数据内嵌，非 fetch 本地文件）
  - [ ] 至少一行 KPI 卡片（≥3 张）
  - [ ] 至少 3 张图表，且类型合理（渠道对比=柱状、时间趋势=折线、占比=环形）
  - [ ] 含明细数据表
  - [ ] 至少 1 条发现识别出信息流 ROI 低于示例参考线 2.0，并说明这是假设参照，实际盈亏需结合成本核对
  - [ ] 至少 1 条发现识别出整体 ROI 逐月下降（约 1.86 → 1.80 → 1.67），注明 6 月只到 13 日；不把不完整月份 GMV 直接当作完整月份对比
  - [ ] 每条发现都有 So What（行动含义）

## 用例 2（编码陷阱 · 正例）

- **真人指令**：「这个 csv 打开是乱码，帮我分析」
- **输入**：一份 `gbk` 编码、含中文列名的销售 CSV
- **期望**：先探测编码（utf-8 失败 → 退 gbk）成功读入，不出现乱码列名；正常产出报告。
- **客观检查项**：
  - [ ] 没有把乱码列名直接当作字段名写进报告
  - [ ] 报告中文显示正常
  - [ ] 过程中体现了编码探测（而非硬编码 utf-8 然后报错放弃）

## 用例 3（多工作表 · 正例）

- **真人指令**：「分析这个 Excel」
- **输入**：含 3 个 sheet 的 `.xlsx`（sheet1=说明页、sheet2=主数据、sheet3=数据字典）
- **期望**：先列出所有 sheet，判断 sheet2 为主数据，不盲目读第一个说明页。
- **客观检查项**：
  - [ ] 报告基于真正的主数据，而非说明页
  - [ ] 明确说明了选择哪个 sheet 及理由

## 用例 4（简单查数 · 反例：不应触发全流程）

- **真人指令**：「这表里 D 板块的总消耗是多少？」
- **输入**：`sample/campaign-data-sample.csv`
- **期望**：直接给出 D 板块消耗合计（一个数字），**不生成 HTML 报告、不走三阶段**。
- **客观检查项**：
  - [ ] 只返回数值答案，没有生成报告文件
  - [ ] 没有把单值查询升级成完整分析

## 用例 5（格式转换 · 反例：不应触发分析）

- **真人指令**：「把这个 csv 转成 json」
- **输入**：任意 CSV
- **期望**：执行格式转换，**不做数据洞察、不生成报告**。
- **客观检查项**：
  - [ ] 产出的是转换后的数据文件，不是分析报告
  - [ ] 没有强行插入"核心发现/建议"

## 用例 6（图表选择合理性 · 正例）

- **真人指令**：「按月看一下销售额变化趋势，再看各品类占比」
- **输入**：含日期、品类、销售额的数据
- **期望**：趋势用**折线图**，品类占比用**环形/柱状图**——绝不用饼图表达趋势。
- **客观检查项**：
  - [ ] 时间趋势用折线图，不是饼图
  - [ ] 占比类别若 >6 个则改用横向柱状图而非环形
  - [ ] 每个核心发现至少配一张图

## 用例 7（数据质量提示 · 正例）

- **真人指令**：「分析这份退货数据」
- **输入**：`sample/campaign-data-sample.csv`（退货率列有 2 行缺失）
- **期望**：在"值得关注"中标注退货率缺失，说明均值是剔除缺失后计算，不假装数据完整。
- **客观检查项**：
  - [ ] 报告"值得关注"中提到缺失/口径风险
  - [ ] 没有把缺失值静默当作 0 计入

## 通用合格门槛（所有正例必须满足）

- [ ] 生成的 HTML 在离线时可显示文本与表格，并明确提示图表需要联网
- [ ] 至少一行 KPI 卡 + 至少 3 张图 + 一张数据表
- [ ] 图表类型与数据关系匹配（见图表选择指南）
- [ ] 发现按重要性排序，标题是结论而非名词
- [ ] 每个数字都有对比参照系（均值/上期/盈亏线/目标）
- [ ] 相关性表述用"相关/伴随"，不乱说"导致"
