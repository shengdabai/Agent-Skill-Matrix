# 小红书爆款文案技能（xhs-hit-copywriter）

> 把一段产品/经历素材，一键改写成有真人感、不像 AI、带钩子的小红书爆款笔记。

**版本**：v1.0.0
**类型**：约束型 + 模板型 Agent Skill
**语言**：中文

---

## 这个技能能做什么

输入一段原始素材（产品介绍 / 使用体验 / 个人经历 / 知识点），技能会输出：
- **3 个候选爆款标题**（基于 12 种验证过的标题公式）
- **1 篇口语化、第一人称、带 emoji 的小红书正文**
- **5-10 个混搭话题标签**（大词 + 精准词 + 长尾词）
- 一句话说明用了什么钩子、规避了哪些违禁词

技能内置的是「经验」：爆款标题怎么起、怎么写才不像 AI、哪些词会被限流、emoji 和标签怎么放才自然。

## 怎么触发

直接用口语说出需求即可，例如：
- 「帮我写篇小红书」
- 「这段话改成种草文案」
- 「做个爆款笔记」
- 「给我的小红书想几个能爆的标题」
- 「帮我写个好物分享/避坑测评」

**不会触发**（超出适用范围）：公众号长文、知乎回答、正式商务文案、新闻稿、说明书、长篇推文。

## 使用示例

**输入：**
> 帮我写篇小红书种草。产品是平价面霜，60块，质地清爽不油腻，适合油皮，我用了两个月回购了。

**输出（节选）：**

候选标题：`用了两个月，我回购了这瓶60元面霜`

正文：
> 这瓶面霜我用了两个月，已经回购了。60元一瓶，质地清爽、不油腻。
> 产品适合油皮，这里分享的是我的使用情况。
> #面霜分享 #平价护肤

未提供购买次数、吸收速度或上妆效果，不添加这些事实。

完整范例见 `references/examples.md`（覆盖好物种草 / 避坑测评 / 经历叙事三品类）。

## 文件结构

```
01-xhs-hit-copywriter/
├── SKILL.md                      # 核心技能（克制原则，正文精简）
├── README.md                     # 本文件
├── PUBLISH-CHECKLIST.md          # 发布前清单
├── references/                   # 重型内容（按需读取）
│   ├── title-formulas.md         # 12 种爆款标题公式 + 例子
│   ├── voice-and-style.md        # 口语化语气 + 去AI味对照 + emoji/标签规范
│   ├── banned-words.md           # 违禁/限流词清单 + 合规替代
│   └── examples.md               # 3 个完整输入→输出范例
└── tests/
    └── test-cases.md             # 评测题库（触发用例 + 客观检查项）
```

技能采用「渐进式披露」：SKILL.md 正文克制精简，重型内容拆到 `references/`，由技能按需读取。

## 依赖说明

**无任何外部依赖。** 不需要 API Key、不调用外部服务、不联网、不依赖第三方库。纯文本技能，开箱即用。

## 兼容性

本技能遵循通用 Agent Skill 标准（YAML frontmatter + Markdown 正文 + references 渐进式披露），兼容：
- **Claude Code** / Claude Agent Skills
- **扣子（Coze）** Skill 体系
- **ClawHub** 技能市场
- 任何遵循 Agent Skills 标准的 Agent 平台

> 不同平台对 frontmatter 字段命名可能略有差异（如 `name`/`description`），上架前按目标平台规范微调即可，正文与 references 无需改动。

## 合规与安全

- 内置《广告法》《化妆品监督管理条例》违禁词意识（绝对化用语、医疗功效宣称、引流词）。
- 素材未提及的功效/数据/价格一律不编造。
- 违禁词清单覆盖高频高危词，不等于穷尽；强监管品类（医疗/医美/金融/母婴）建议额外核对最新平台公约。

## 许可

可自由用于个人及商业内容创作。
