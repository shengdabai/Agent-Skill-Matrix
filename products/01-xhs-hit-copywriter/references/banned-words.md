# 小红书违禁 / 限流词清单 + 合规替代说法

完稿后**必须**逐句对照本清单自检。违规词会导致笔记限流、不被推荐，甚至涉及《广告法》《化妆品监督管理条例》风险。原则：**宁可保守，不踩红线；没把握的功效一律不写。**

---

## 一、绝对化用语（《广告法》明令禁止）

这类词最高可处 20 万罚款，平台必限流。

| ❌ 禁用 | ✅ 替代说法 |
|--------|-----------|
| 最好 / 最佳 / 最强 / 最优 | 很喜欢 / 个人很爱 / 我心里的 top |
| 第一 / 唯一 / 销量第一 | 我回购最多的 / 闭眼入的那个 |
| 国家级 / 世界级 / 顶级 | 品质在线 / 用料扎实 |
| 100% / 绝对 / 永久 | 几乎 / 基本上 / 用了挺久 |
| 史上最 / 全网最低 | 价格挺香 / 性价比我觉得可以 |
| 极致 / 完美 / 无敌 | 真的很戳我 / 体验感拉满 |

## 二、医疗 / 功效宣称（化妆品、保健品高危）

化妆品**不得宣称医疗效果**，食品/保健品**不得宣称治疗疾病**。

| ❌ 禁用 | ✅ 替代说法 |
|--------|-----------|
| 治疗 / 治愈 / 疗效 / 药用 | （护肤品类避免提，可说「我用着舒服」） |
| 祛斑 / 去斑 / 淡斑（强功效） | 提亮肤色感受 / 看起来气色好一点 |
| 祛痘 / 消炎 / 杀菌 | 痘痘期用着没负担 / 清爽不闷 |
| 抗炎 / 修复屏障（医疗向） | 用着比较温和 / 没有刺激感 |
| 美白（强宣称） | 提亮 / 用了气色更透一点 |
| 生发 / 防脱（药效向） | 头发护理感受 / 用着头皮舒服 |
| 瘦身 / 减肥 / 燃脂 | 身材管理 / 我的饮食搭配 |
| 排毒 / 养颜 | 喝着舒服 / 我的日常习惯 |
| 抗癌 / 防癌 / 降三高 | （健康类一律不得宣称疾病功效） |
| 纯天然 / 无添加 / 零激素 | 成分表我贴出来大家自己看 |

## 三、引流 / 营销违规词（触发限流）

平台限制站外引流和硬广。

| ❌ 禁用 | ✅ 替代说法 |
|--------|-----------|
| 加微信 / 微信号 / 加V / 私我 | 评论区聊 / 主页有更多 |
| 链接 / 购买链接 / 下单（硬广） | 自己去搜 / 放在那个软件了 |
| 代购 / 一手货源 / 招代理 | （避免出现，易判营销号） |
| 免费送 / 抽奖 / 点赞抽 | （站外抽奖违规，谨慎） |
| 最低价 / 全网最便宜 / 限时秒杀 | 价格挺友好 / 这个价我觉得值 |
| 官方正品 / 假一赔十 | 我买的渠道是X / 自己认准 |

## 四、敏感 / 易判违规内容

- **绝对化承诺**：「一定瘦」「保证有效」「无效退款」→ 改为分享个人体验。
- **比较贬低**：直接点名贬低竞品 → 改为只夸自己用的，不踩别家。
- **金融诱导**：「稳赚」「躺赚」「月入过万必看」→ 弱化收益承诺，写真实过程。
- **虚假人设**：编造身份（「三甲医生告诉你」）→ 没有就不编。
- **谐音错字钻空子**：用「zhi疗」「祛dou」绕审 → 不推荐，仍可能被识别，且影响阅读。

## 五、自检流程（完稿必做）

1. 通读全文，搜索本清单第一栏所有禁用词。
2. 命中即替换为对应合规说法。
3. 重点扫三类：绝对化词（最/第一/100%）、医疗功效词（治疗/祛斑/美白）、引流词（微信/链接）。
4. 涉及美妆/保健/食品品类时，功效描述全部降级为「个人体感」而非「客观功效」。
5. 拿不准的功效宣称 → 删掉，不冒险。

> 提示：平台规则会更新，本清单覆盖高频高危词，不等于穷尽。涉及医疗、医美、金融、母婴等强监管品类时，建议用户额外核对最新《小红书社区公约》和《广告法》。
