# 口语化语气规范 + 去 AI 味对照 + emoji/标签规范

本文件定义小红书笔记的「质感」。所有正文必须通过这里的语气检查。

---

## 一、口语化语气规范

小红书的笔记是「人在说话」，不是「文章在陈述」。把握以下几点：

### 1. 第一人称体验视角，全程不掉
始终是「我」在分享：我用了、我发现、我踩过坑、我回购了。读者信任的是一个真实的人，不是一份说明书。

### 2. 短句为主，长句拆开
手机阅读，一句话别超过一行半。
- 改前：「这款面霜质地非常轻薄并且吸收很快同时保湿效果持久。」
- 改后：「质地超轻薄，一抹就吸收。保湿能扛一整天。」

### 3. 多用语气词和网络口语
适度使用：真的、绝了、谁懂、家人们、姐妹们、冲、yyds、巨、超、好家伙、属于是、有被惊艳到、哈哈哈、救命、笑死、awsl。
- 注意：用得自然，别一句一个，否则像装。

### 4. 允许不完美和小情绪
真人会吐槽、会有私心、会犹豫。适当暴露缺点反而增加可信度。
- 例：「缺点不是没有，瓶子是真的丑哈哈哈，但是不影响我回购。」

### 5. 制造对话感
偶尔直接对读者说话，像在私聊。
- 例：「相信我，先收藏再说。」「姐妹别犹豫了。」「你也有这个困扰对吧？」

### 6. 节奏有起伏
重点处可以用单独一行短句强调，或用「。。。」制造停顿、用「！」给情绪。

## 二、去 AI 味对照表（反面 → 正面）

| 维度 | ❌ AI 味（禁止） | ✅ 真人味（推荐） |
|------|----------------|------------------|
| 开头 | 在快节奏的现代生活中… | 打工人真的需要这个！ |
| 连接 | 首先…其次…综上所述 | （直接分点，或用「然后」「反正」「重点是」） |
| 形容 | 极致/卓越/匠心/赋能/沉浸式 | 绝了/上头/真香/谁懂啊/巨好用 |
| 卖点 | 不仅…而且…更重要的是 | 最惊喜的是…（只突出一个最戳的点） |
| 结论 | 综上，值得入手 | 反正我回购了三次了 |
| 客观腔 | 各方面表现均衡无短板 | 缺点也有啊但瑕不掩瑜 |
| 对仗 | 它是品质象征，更是态度 | 就，很懂我那种感觉 |
| 数据 | 临床证实有效率99% | （没数据就写真实体感，绝不编） |
| 号召 | 立即购买，限时优惠 | 链接放评论区了，自己冲～ |

### AI 味高频违规词（出现即改写）
赋能、打造、匠心、极致、卓越、沉浸式、一站式、全方位、深耕、助力、不难发现、值得一提的是、综上所述、总而言之、在……的今天、随着……的发展、不仅……而且……更重要的是。

## 三、emoji 使用规范

emoji 是小红书的「情绪标点」，放对了加分，放滥了像微商。

- **数量**：全文 3-8 个为宜（不含标题）。标题 1-2 个。
- **位置**：放在情绪点、段首引导、或分点项目符号处。
- **不要**：每句话尾都塞 emoji；同一个 emoji 连用三次以上；与文意无关的乱配。
- **选择**：贴合内容语义。护肤用 🧴💧✨、美食用 🍜☕️😋、好物用 💸🛒🔥、情绪用 😭🥹😮‍💨、强调用 ⚠️👀💡。
- **分点符号**可用 emoji 替代序号，更有小红书感：
  ```
  ✅ 优点一
  ✅ 优点二
  ⚠️ 注意事项
  ```

## 四、话题标签规范

标签决定笔记被多少人和哪些人看到。结尾放标签行。

- **数量**：5-10 个 `#话题#`，统一放正文末尾。
- **结构混搭**（关键）：
  - 大词（高流量，2-3 个）：如 `#好物分享` `#护肤`
  - 精准人群词（2-3 个）：如 `#油皮护肤` `#学生党平价好物`
  - 长尾场景/痛点词（2-4 个）：如 `#换季烂脸` `#出租屋改造`
- **不要**：只堆大词（会被淹没）；堆与内容无关的蹭热度词（限流风险）。
- **格式**：`#标签#` 之间空格隔开，例：
  ```
  #平价护肤 #油皮亲测 #面霜推荐 #学生党好物 #换季护肤 #成分党
  ```

## 五、整体结构模板（参考，非死框）

```
【钩子开头 1-2 句】戳痛点 / 抛结果 / 制造好奇

【正文主体】分点或分段，每段 2-3 行，第一人称体验
✅ 点一（带具体细节）
✅ 点二
⚠️ 小吐槽或注意点（增加真实感）

【结尾】行动指引 / 情绪共鸣，一句话收尾

【标签行】#大词 #精准词 #长尾词（5-10 个）
```
