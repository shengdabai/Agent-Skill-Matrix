# 小红书爆款文案改写技能

把用户给的一段原始素材（产品介绍 / 使用体验 / 个人经历 / 知识点），转写成一篇符合小红书平台调性、读起来像真人分享、自带阅读钩子的爆款笔记。

本技能装的是经验，不是规则的堆砌：什么样的标题会被点开、怎么写才不像 AI、哪些词会被限流、emoji 和标签怎么放才自然。核心是「约束输出质感」——交付一篇能直接复制粘贴发布的笔记。

## 适用范围

- 适用：单篇小红书笔记（种草、测评、教程、避坑、好物分享、个人经历叙事）。
- 不适用：公众号长文、知乎回答、商务/正式文案、新闻稿、说明书。遇到这类需求，提示用户这不是本技能的场景。
- 篇幅约束：小红书正文建议 200-800 字，过长会劝退读者。超出范围时主动收敛。

## 核心理念

小红书爆款的本质是「真实的人在分享真实的体验」。AI 味是最大的敌人——一旦读者感觉到「这是机器写的/这是广告」，立刻划走。所以本技能所有动作都服务于一个目标：**忠实表达素材，用清楚、自然的语言分享信息；只有用户确认亲自体验过，才写第一人称使用经历。**

## 工作流程

按以下步骤执行，不要跳步：

### 第 1 步：吃透素材，确认信息
- 通读用户给的原始素材，提取：产品/主题是什么、核心卖点或经历亮点、目标人群、用户想要的语气（如有）。
- **先判断素材类型**：本人体验可使用已确认的第一人称；只有产品介绍时用产品资料视角，或追问真实体验。不得新增“我用过/回购过”等身份与经历。
- **缺什么不要编**：素材没提到的功效、数据、价格一律不得编造。信息不足时，先问用户 1-2 个关键问题（如「主要想突出哪个点」），或用占位标记 `[此处需补充具体数据]` 让用户填。

### 第 2 步：定笔记类型与人群
- 判断笔记类型：种草 / 测评 / 教程 / 避坑 / 经历叙事。不同类型钩子不同。
- 锁定说话对象（如「熬夜党」「租房党」「新手妈妈」），全文用对这群人说话的口吻。

### 第 3 步：起标题（最关键）
- 标题影响读者是否愿意继续阅读。一次产出 3 个候选标题供用户选。
- **如需爆款标题公式，读 references/title-formulas.md**，按公式套用并结合素材。
- 标题硬要求：≤20 字最佳；含数字 / 痛点 / 情绪词 / 身份标签其中至少一个；带 1-2 个相关 emoji；不标题党到与正文不符。

### 第 4 步：写正文
- 开头 1-2 句必须是钩子（戳痛点 / 抛结果 / 制造好奇），不要铺垫。
- 中间分点或分段，每段短（手机一屏读得完），多用口语、短句；第一人称体验仅限用户提供或确认的经历。
- 结尾给行动指引或情绪共鸣（如「冲就完事了」「姐妹们快去」）。
- **如需口语化语气规范、去 AI 味对照、emoji 与标签放置规范，读 references/voice-and-style.md**。

### 第 5 步：配 emoji 与话题标签
- emoji：穿插在句中或段首点缀情绪，不要每句都放，3-8 个为宜。
- 标签：结尾放 5-10 个 `#话题#`，混合大词（流量）+ 精准词（人群）+ 长尾词。
- 具体规范见 references/voice-and-style.md。

### 第 6 步：违禁词自检
- 完稿后逐句扫一遍违禁/限流词，替换为合规说法。
- **必须读 references/banned-words.md** 对照检查，尤其涉及医疗、美妆、绝对化用词时。

### 第 7 步：交付
- 输出格式：3 个候选标题 + 1 篇完整正文（含 emoji）+ 标签行。
- 末尾附一句话说明：用了哪个钩子、规避了哪些违禁词，方便用户判断。

完整范例见 references/examples.md（覆盖好物种草、避坑测评、经历叙事等不同品类）。

## 禁止清单（去 AI 味）

以下为语言风格对照。正面示例中的使用时长、回购、体感、包装等事实，只有与用户素材一致时才能采用，不得直接套用为用户经历。

1. **禁止排比堆砌 / 三段式总分**
   - 反面：「它不仅外观精致，而且功能强大，更重要的是性价比超高。」
   - 正面：「外观真的绝了📸 用了一周，最惊喜的是居然这么便宜。」

2. **禁止书面连接词**（首先/其次/综上所述/总而言之/值得一提的是/不难发现）
   - 反面：「综上所述，这款产品值得入手。」
   - 正面：「反正我是回购了。」

3. **禁止空洞形容词堆砌**（卓越/极致/匠心/赋能/打造/沉浸式体验）
   - 反面：「为您打造极致的沉浸式护肤体验。」
   - 正面：「敷上去凉凉的，第二天起来脸真的不干了。」

4. **禁止完美无瑕的客观腔**——真人会有小吐槽、小私心
   - 反面：「该产品各方面表现均衡，无明显短板。」
   - 正面：「缺点也有啊，包装丑了点，但东西是真好用。」

5. **禁止破折号串长句 / 过度对仗**
   - 反面：「它，是品质的象征——更是生活的态度。」
   - 正面：「就，很懂打工人的那种。」

6. **禁止假大空开头**（在快节奏的现代生活中 / 随着……的发展）
   - 反面：「在快节奏的都市生活中，我们需要一杯好咖啡。」
   - 正面：「打工人续命刚需，这杯我能吹一年☕️」

7. **禁止编造数据和功效**——没有就不写，绝不杜撰销量、成分、临床效果。

正向语气示范与更多对照，见 references/voice-and-style.md。

## 踩坑点（真实易错）

- **标题党反噬**：标题夸过头、正文兑现不了，读者点进来失望，互动数据反而崩。标题可以有钩子，但不能骗。
- **emoji 滥用**：每句话尾都塞 emoji，看着像微商。点缀情绪即可。
- **标签全堆大词**：只放 `#好物 #分享` 这种巨流量词，会被淹没；要搭精准长尾词锁定人群。
- **第一人称用丢**：写着写着滑回客观说明书腔。全程盯住「我」的体验视角。
- **违禁词漏网**：美妆/医疗/食品类最易踩雷（「祛斑」「治疗」「最」「第一」），完稿必过 banned-words 自检。
- **段落太长**：一段写成五行，手机上是一堵墙。两三行就分段。
- **把广告写成广告**：硬广话术（「立即购买」「限时优惠」）会触发限流，要软植入。
- **忽略人群定位**：对所有人说话 = 对谁都没说话。先锁定一类人再开写。
