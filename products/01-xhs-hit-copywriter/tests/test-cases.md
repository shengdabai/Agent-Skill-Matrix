# 评测题库（书 6.4 评测方法）

用于验证技能是否被正确触发、输出是否达标。包含「真人式触发指令 + 输入 + 期望结果」的端到端用例，以及客观检查项。

---

## 一、触发与输出用例

### 用例 1：标准种草触发（应触发）
**指令**：「帮我写篇小红书种草文案，产品是一款保温杯，能保温12小时，颜值高，适合上班族。」
**输入素材**：保温杯 / 保温12h / 高颜值 / 上班族
**期望结果**：
- 技能被触发。
- 输出 3 个候选标题（≤20字、带 emoji、含钩子要素）。
- 1 篇产品资料视角的口语化正文，分段短、有 emoji；未确认本人体验时不得出现“我用了”“我回购”等经历。
- 结尾 5-10 个混搭话题标签。
- 无违禁/绝对化词。
- 「保温12小时」可写（素材有），不得编造未提及的功效。

### 用例 2：口语化模糊触发（应触发）
**指令**：「这段话帮我改成爆款笔记呗」（附一段产品介绍）
**期望结果**：技能被触发（「爆款笔记」是触发词），按完整工作流输出标题+正文+标签。

### 用例 3：标题需求触发（应触发）
**指令**：「给我的小红书想几个能爆的标题，主题是租房改造」
**期望结果**：技能被触发，调用 title-formulas.md，产出 3+ 个不同公式的候选标题，每个 ≤20 字带 emoji，不强行输出全文（用户只要标题）。

### 用例 4：违禁词处理用例（应触发 + 合规）
**指令**：「写篇美白精华的种草文案，主打祛斑美白效果。」
**期望结果**：
- 技能被触发。
- 输出中**不得出现**「祛斑」「美白」强功效宣称、「最」「100%」等绝对化词。
- 不得把产品功效改编为个人体感；未提供实际体验时先追问或删去未证实的体验结果。
- 末尾说明已规避哪些违禁词。

### 用例 5：信息不足用例（应触发 + 不编造）
**指令**：「写个面膜的小红书爆款」（无任何产品细节）
**期望结果**：技能被触发，但不编造卖点/数据，先向用户追问 1-2 个关键问题（品类卖点/人群），或用 `[需补充]` 占位。

### 用例 6：反例——公众号长文（不应触发本技能）
**指令**：「帮我写一篇公众号长文，3000字深度分析新能源汽车行业。」
**期望结果**：
- 技能**不被触发**（description 反向触发词明确排除公众号长文）。
- 若误入，应主动说明「这是公众号长文场景，不适合本小红书技能」并退出。

### 用例 7：反例——正式商务文案（不应触发）
**指令**：「写一份正式的产品发布新闻稿。」
**期望结果**：技能不触发；属 description 排除范围（新闻稿/正式文案）。

## 二、客观检查项（每次输出逐条核对）

1. **标题数量与长度**：是否产出 ≥3 个候选标题，且每个 ≤20 字（最长不超 28）？
2. **钩子要素**：每个标题是否含数字/痛点/情绪/身份/反差/悬念至少一项，且带 1-2 个 emoji？
3. **事实视角**：第一人称经历是否来自本人素材？仅有产品资料时是否未编造使用、回购或体验？
4. **去 AI 味**：是否无禁用连接词（首先/综上所述）、无空洞形容词（极致/赋能/沉浸式）、无假大空开头（在快节奏的……）？
5. **emoji 数量**：正文 emoji 是否在 3-8 个，未滥用（非每句尾都塞）？
6. **标签结构**：是否 5-10 个标签，且大词+精准词+长尾词混搭，非纯堆大词？
7. **违禁词清零**：是否无绝对化词（最/第一/100%）、无医疗强功效词（治疗/祛斑/美白）、无引流词（微信/链接）？
8. **不编造**：素材未提及的功效/数据/价格是否一律未杜撰？
9. **段落长度**：正文是否每段 2-3 行内，无五行长墙？
10. **交付完整性**：是否含 3 标题 + 完整正文 + 标签行 + 一句话规避说明？

> 评分建议：用例 1-7 逐个跑，判断触发是否正确 + 输出是否达标；客观检查项 1-10 作为每篇输出的 checklist，全过才算合格。
