# resume-star-optimizer

把流水账式工作经历优化成专业、量化、ATS 友好的简历 bullet points 的 Agent Skill。
基于 STAR 模型，将简历顾问的隐性判断固化成可执行的五步 SOP。

- **版本**：v1.0.0
- **类型**：流程型 + 约束型技能
- **语言**：中文（标识符英文），支持优化中/英文简历

## 它解决什么问题

普通人写简历爱写"做了什么"（职责），HR 和 ATS 想看"达成了什么"（成果）。
本技能把经历从"流水账"转换为"强动词 + 量化结果 + 业务价值"的成果型条目，并对齐 ATS 关键词，提升简历通过率。

核心原则：**技能给经验，不编造数据**。缺数字时主动追问用户，问不到就定性表达 + 标注待补，绝不虚构。

## 五步流程

1. **检查输入** —— 经历够具体则继续，太空泛先追问
2. **STAR 拆解** —— 拆进 Situation / Task / Action / Result
3. **量化追问**（强制人工确认点）—— 没数字时问用户，不编造
4. **动词强化 + ATS 对齐** —— 弱动词换强动词，融入 JD 关键词
5. **输出 bullet + 自检** —— 按黄金结构产出，过自检清单再交付

## 示例输入 / 输出

**输入（用户给的流水账）**
> 负责公司微信公众号的运营，参与内容策划，配合完成粉丝增长。

**技能会先追问**（量化追问点）
> 运营了多久？粉丝从多少涨到多少？每周发几篇？有没有爆款或带来的转化？

**用户补充**：运营 1 年，6000→4 万，每周 3 篇，2 篇 10 万+，带动线下报名。

**输出（成果型 bullet）**
- 运营企业微信公众号 1 年，粉丝量从 6000 增长至 4 万。
- 参与内容策划，每周发布 3 篇内容，产出 2 篇 10 万+文章。
- 通过内容带动线下活动报名。[建议补充真实报名数据]

## 文件结构

```
resume-star-optimizer/
├── SKILL.md                      # 核心：五步流程 + STAR 模型 + 禁止清单 + 踩坑点 + 安全
├── references/
│   ├── action-verbs.md           # 强动词库（按职能分类 + 弱→强对照）
│   ├── ats-keywords.md           # ATS 对齐指南 + 4 行业关键词 + JD 匹配法
│   └── star-examples.md          # 4 个完整 before→after 范例 + 量化追问清单 + 禁止反例
├── tests/
│   └── test-cases.md             # 8 个评测用例（含 2 个反向触发用例）
├── README.md                     # 本文件
└── PUBLISH-CHECKLIST.md          # 发布前清单（重点：隐私清理）
```

技能采用渐进式披露：SKILL.md 保持克制，详细库（动词、关键词、范例）按需从 `references/` 读取。

## 依赖说明

**无外部依赖**。纯文本/Markdown 技能，不调用任何 API、MCP、网络服务或第三方库，开箱即用。

## 兼容性

- 兼容 Claude Code 及任何支持 Agent Skills（SKILL.md + YAML frontmatter）规范的环境。
- 不依赖特定模型版本；任何具备指令遵循能力的对话模型均可运行。
- 离线可用（除非用户自行要求联网搜 JD，本技能本体不联网）。

## 安全与隐私

本 Skill 不主动调用外部工具或写入文件；数据如何传输与留存取决于宿主平台。使用前先删除不必要的个人信息。
优化 bullet 不需要身份证、住址、银行卡等敏感字段。详见 SKILL.md「安全」一节与 PUBLISH-CHECKLIST.md。

## 边界（不做什么）

- 不写求职信（cover letter）
- 不做模拟面试问答
- 不写领英长文自述 / 自我介绍口播稿
- 不编造任何数字、头衔或时间
