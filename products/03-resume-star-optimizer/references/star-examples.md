# STAR 改写范例 + 量化追问清单 + 禁止反例

## 空泛信号词（第一步判断输入是否太空泛用）

经历里如果**主要由**以下词构成、且无任何具体动作/对象/数字，判定为"太空泛"，先追问再拆解：

- 职责套话：负责、参与、协助、配合、辅助、跟进、相关工作、日常事务、各项任务
- 模糊范围：一些、多个、各种、若干、相关、有关、等等
- 无对象动词：做、搞、处理、完成、维护（后面不接具体对象时）
- 自封形容：优秀的、超强的、丰富的、资深的（无事实支撑）

判断口径：一句话里如果**删掉空泛词后几乎不剩具体信息**，就要追问。

## 量化追问清单（第三步用，按维度选 2-3 个最关键的问）

### 规模维度
- 你服务/影响了多少人（用户、客户、学员、读者）？
- 你管理的预算 / 团队规模 / 账号数量 / SKU 数是多少？
- 覆盖了多大范围（城市、区域、渠道数）？

### 变化维度（最有说服力）
- 这个指标从多少变到了多少？
- 提升 / 下降了百分之多少？
- 对比之前 / 同行 / 目标，好了多少？

### 效率维度
- 节省了多少时间 / 人力 / 成本？
- 把某流程从多久缩短到了多久？
- 效率/产能提升了几倍？

### 频次 / 产出维度
- 每周 / 每月做多少次、产出多少（篇、个、单、场）？
- 持续了多长时间？

### 业务结果维度
- 带来了多少营收 / GMV / 利润 / 转化？
- 拉新 / 留存 / 复购 / 续约率是多少？
- 拿到过什么排名、奖项、认可？

> 追问礼仪：一次问 2-3 个，给例子降低回忆门槛（"比如粉丝从几千涨到几万？"），不要一次抛十个问题。

## 完整改写范例（before → after，覆盖 4 个职能）

### 范例 1：运营岗

**Before**：负责公司微信公众号的日常运营工作，参与内容策划，配合完成粉丝增长任务。

**量化追问后用户补充**：运营 1 年；粉丝从约 6000 涨到约 4 万；每周发 3 篇；有 2 篇 10 万+；带动了线下活动报名。

**After**
- 运营企业微信公众号 1 年，粉丝量从约 6000 增长至约 4 万。
- 参与内容策划，每周发布 3 篇内容，产出 2 篇 10 万+文章。
- 通过内容带动线下活动报名。[建议补充真实报名数据]

**来源核对**：数字均直接来自补充；没有独立负责、全年产量或到场率证据，不作此声明。用户只说明参与，不升级为独立主导。

### 范例 2：技术 / 研发岗

**Before**：负责后端开发，处理一些线上问题，参与系统优化。

**量化追问后用户补充**：用 Go 重构订单服务；接口响应从 800ms 降到 200ms；线上故障明显减少；支撑大促流量。

**After**
- 使用 Go 重构订单服务，接口响应时间从 800ms 降至 200ms。
- 支撑大促流量，线上故障明显减少。[建议补充真实流量与故障数据]

**来源核对**：Go、订单服务、响应时长、大促和故障变化直接来自补充；未提供平均/峰值口径、限流方案、QPS、零故障或异常率，不添加。

### 范例 3：市场 / 品牌岗

**Before**：参与广告投放，协助做品牌推广，完成相关营销活动。

**量化追问后用户补充**：管理信息流投放预算每月 30 万；ROAS 从 1.8 提升到 3.2；策划过一次品牌活动曝光几百万。

**After**
- 管理每月 30 万元信息流投放预算，ROAS 从 1.8 提升至 3.2。
- 策划品牌活动，曝光达到几百万。[建议补充真实曝光量及统计口径]

**来源核对**：预算、ROAS、活动和模糊曝光范围均来自补充；不把“几百万”写成具体值，不添加联名、热榜或 CPA。

### 范例 4：产品岗

**Before**：负责产品的需求，做了一些功能优化，参与版本迭代。

**量化追问后用户补充**：主导会员体系改版；通过 A/B 测试验证；付费转化率提升；推动了 4 个版本上线。

**After**
- 主导会员体系改版，通过 A/B 测试验证，付费转化率提升。[建议补充真实转化率]
- 推动 4 个版本上线。

**来源核对**：主导、测试、转化改善和版本数直接来自补充；未提供方案数、跨端、按期、留存率，不添加。

## 禁止清单 · 更多反面例子（约束型加强）

### 假大空型
- ✗ 「全面负责部门各项工作，推动公司整体发展」→ 信息量为零
- ✗ 「积极配合领导，认真完成本职工作」→ 这是态度不是成果
- ✓ 改法：拆出 2-3 件**具体**做过的、有结果的事，逐条量化

### 无量化型
- ✗ 「提升了用户活跃度」→ 提升多少？
- ✗ 「优化了团队协作效率」→ 怎么衡量？
- ✓ 改法：追问数字；实在没有则定性 + 标注「建议补充数据」

### 主观夸大型
- ✗ 「拥有卓越的沟通能力和超强执行力」→ 自我评价不可验证
- ✗ 「公司的顶梁柱，无可替代」→ 空洞且不专业
- ✓ 改法：用事实让能力自己说话——「3 个月内独立谈成 12 家渠道合作」

### 编造数字型（最危险，背调会戳破）
- ✗ 用户只说"做了用户增长"，技能擅自写「用户增长 200%」
- ✗ 用户没提营收，技能写「贡献营收百万」
- ✓ 改法：只写用户确认过的数字；无数据时绝不虚构，宁可定性表达并标注待补

> 技能自检铁律：**每一个出现在 bullet 里的数字，都必须能追溯到用户本人提供或确认。** 找不到来源的数字，删掉或改追问。
