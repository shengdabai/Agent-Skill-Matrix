# ATS 关键词对齐指南

## 什么是 ATS，为什么要对齐

ATS（Applicant Tracking System，简历追踪/筛选系统）是企业用来自动筛选简历的软件。
大量简历在到达 HR 眼前**之前**，先被 ATS 按关键词匹配度打分、排序、甚至直接刷掉。

核心逻辑：ATS 把简历文本与 **JD（职位描述）** 做关键词匹配。简历里出现 JD 要求的硬技能、工具、职责关键词越多（且语境自然），匹配分越高，越容易进入人工筛选环节。

**目标**：让简历"说 JD 的语言"，同时保持真实、通顺、成果导向——不是关键词作弊堆砌。

---

## 如何匹配 JD（四步法）

### 第一步：提取 JD 关键词
从目标 JD 里圈出三类词：
1. **硬技能 / 工具**：Python、SQL、Figma、Google Analytics、Photoshop、ROI 模型……
2. **职责动词 / 领域词**：用户增长、A/B 测试、需求评审、供应链管理、内容运营……
3. **高频名词**：JD 里反复出现的词（出现 3 次以上的，几乎一定是评分权重词）。

### 第二步：分类——必备 vs 加分
- JD 中"任职要求 / 必须 / required"段落里的 → **必备关键词**，简历必须覆盖（前提是用户真的具备）。
- "加分项 / preferred / nice to have" → **加分关键词**，有则自然带上。

### 第三步：自然融入 bullet
把关键词嵌进真实的成果句里，**不是单独堆一行关键词**。
- ✗ 关键词作弊：「精通 Python、SQL、数据分析、A/B 测试、用户增长、ROI」（一串名词，ATS 新版会识别为堆砌）
- ✓ 自然融入：「用 **Python + SQL** 搭建用户行为分析看板，通过 **A/B 测试** 优化转化路径，季度 ROI 提升 28%」

### 第四步：术语对齐（同义词归一）
JD 用什么词，简历就尽量用什么词（在真实前提下）。
- JD 写 "用户留存"，简历别只写"复购"——补一个"留存"。
- JD 写 "B2B 销售"，简历别只写"企业客户开发"——对齐成"B2B"。
- 缩写与全称都覆盖一次：如 "搜索引擎优化（SEO）"，让 ATS 两种写法都能命中。

## ATS 友好的格式底线（避免被解析失败）

- 用标准章节标题（工作经历 / 教育背景 / 技能），别用创意标题（"我的旅程"）。
- 避免把关键信息塞进**页眉页脚、文本框、图片、表格**——很多 ATS 解析不出来。
- 用常规字体、标准项目符号（•、-），别用特殊符号画图。
- 文件格式优先 .docx 或 ATS 可解析的 PDF。
- 日期格式统一（如 2021.03 – 2023.06）。

> 本技能只优化 bullet 文本内容；格式排版提醒用户在简历模板里遵守以上规则。

## 分行业关键词示例（仅供参考，须以真实 JD 为准）

### 技术 / 研发岗
- 硬技能：Python / Java / Go、SQL、Git、Docker、Kubernetes、CI/CD、微服务、REST API、单元测试、性能优化
- 领域词：系统设计、高并发、分布式、代码审查、技术方案、线上稳定性、监控告警
- 强动词搭配：开发、重构、优化、部署、提速、修复

### 运营岗（内容/用户/活动）
- 硬技能：内容运营、用户运营、活动运营、社群运营、数据分析、Excel/SQL、私域、SOP
- 领域词：拉新、留存、转化、复购、GMV、DAU/MAU、漏斗、用户画像、增长策略
- 平台词：微信公众号、小红书、抖音、视频号、企业微信、社群
- 强动词搭配：运营、拉新、转化、策划、复盘、增长

### 市场 / 品牌岗
- 硬技能：投放（信息流/SEM）、Google Ads、Meta Ads、SEO/ASO、品牌策划、PR、活动策划、ROI 测算
- 领域词：品牌定位、整合营销、媒介投放、KOL/KOC、声量、曝光、转化成本（CPA/CPL）、ROAS
- 强动词搭配：策划、投放、撬动、谈判、提升、放大

### 产品岗
- 硬技能：需求分析、PRD、原型设计（Axure/Figma）、用户调研、数据驱动、A/B 测试、竞品分析
- 领域词：需求评审、版本迭代、用户体验、功能优先级、增长闭环、北极星指标、留存/转化
- 强动词搭配：定义、设计、推动、量化、迭代、上线

## 没有 JD 时怎么办

用户没提供目标 JD → 用该职能的**通用核心关键词**（上表）做基础对齐，并提示用户：

> 「你没提供目标职位的 JD。我先用 [职能] 的通用关键词优化。如果你能贴一份目标 JD，我可以做精准关键词匹配，显著提升 ATS 通过率。」

不要为了凑关键词，给用户安上他不具备的技能——那是编造（违反禁止清单第 4 条）。
