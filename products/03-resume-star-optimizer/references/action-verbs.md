# 强动词库（Action Verbs）

简历 bullet 的第一个词决定第一印象。**用强动词开头，体现主动性、方法和影响力**，避免"负责/参与/协助"这类弱被动词。

## 使用方法

1. 先判断这条 bullet 属于哪个职能维度（领导 / 分析 / 创造 / 沟通 / 执行 / 改进 / 增长）。
2. 从对应类别选一个**最贴合实际动作**的强动词。
3. 不要为了"显得强"而夸大——做的是"协调"就别写"统帅"。
4. 同一份简历里避免重复用同一个动词开头，从库里换近义强词。

---

## 弱动词黑名单（见到就替换）

| 弱动词 | 问题 | 替换方向 |
|--------|------|---------|
| 负责 | 只表职责不表成果 | 按实际动作换：主导 / 搭建 / 运营 / 管理 |
| 参与 | 弱化贡献，像打杂 | 协同推动 / 主导某模块 / 贡献于 |
| 协助 | 配角感 | 支持并推动 / 与…协作完成 |
| 帮忙 / 帮 | 口语、无专业感 | 支持 / 赋能 / 协调 |
| 做 / 搞 | 模糊 | 具体动作：设计 / 执行 / 落地 |
| 处理 | 笼统 | 解决 / 化解 / 攻克 / 优化 |
| 完成 | 平淡 | 交付 / 达成 / 推动落地 |
| 了解 / 熟悉 | 不是成果 | 掌握并应用 / 运用…实现 |

## 1. 领导 / 管理类（Leadership）

适用：带团队、跨部门协调、项目统筹、决策。

带领、主导、统筹、组建、培养、指导、驱动、协调、督导、赋能、整合、调度、把控、孵化、推动

弱→强示例：
- 负责团队管理 → **带领** 8 人产品团队，季度需求交付准时率从 70% 提升至 95%
- 参与跨部门项目 → **统筹** 市场/技术/客服三方资源，主导大促项目按时上线

## 2. 分析 / 研究类（Analytical）

适用：数据分析、调研、诊断、建模、评估。

分析、洞察、诊断、量化、评估、建模、拆解、预测、复盘、挖掘、归因、测算、调研、监测、识别

弱→强示例：
- 做数据统计 → **量化分析** 用户流失路径，定位 3 个关键流失节点，挽回月流失 12%
- 了解市场情况 → **调研** 6 家竞品定价策略，输出差异化定价方案被采纳

## 3. 创造 / 设计类（Creative / Build）

适用：从 0 到 1、设计、开发、内容生产、产品搭建。

搭建、设计、开发、创建、构建、打造、策划、孵化、原型化、重构、定义、研发、撰写、产出、上线

弱→强示例：
- 做了一个小程序 → **从 0 搭建** 会员小程序，上线 3 个月注册用户破 5 万
- 写文案 → **策划并撰写** 系列推文 40 篇，篇均阅读 1.2 万，3 篇 10 万+

## 4. 沟通 / 影响类（Communication）

适用：对外谈判、对内汇报、培训、客户关系、说服。

谈判、说服、推介、对接、宣讲、谈成、维系、斡旋、撮合、培训、倡导、汇报、答疑、主持、促成

弱→强示例：
- 联系客户 → **对接并维系** 30+ 大客户，年度续约率 88%
- 跟供应商谈 → **谈判** 采购合同，单价下压 15%，年节省成本 40 万

## 5. 执行 / 交付类（Execution）

适用：落地、运营、运维、流程执行、按期产出。

落地、交付、执行、运营、实施、推进、部署、上线、管控、维护、保障、达成、履约、跟进、闭环

弱→强示例：
- 负责日常运营 → **运营** 抖音企业号，3 个月涨粉 8 万，带动到店核销 2300 单
- 完成项目 → **按期交付** 5 个迭代版本，零线上重大事故

## 6. 改进 / 优化类（Improvement）

适用：提效、降本、流程优化、问题修复、体验提升。

优化、提升、精简、降本、增效、改进、革新、修复、加固、标准化、自动化、重塑、升级、提速、收敛

弱→强示例：
- 优化了流程 → **优化** 审批流程，环节从 9 步压缩至 4 步，平均时长缩短 60%
- 修了一些 bug → **修复** 核心支付链路缺陷，将订单失败率从 3.1% 降至 0.4%

## 7. 增长 / 业务结果类（Growth / Results）

适用：营收、用户、转化、市场份额等业务结果。

增长、提升、转化、拉新、变现、扩张、渗透、激活、留存、复购、突破、贡献、带动、撬动、放大

弱→强示例：
- 做用户增长 → **拉新** 渠道组合优化，单月新增用户 +35%，获客成本下降 22%
- 帮公司赚钱 → **撬动** 老客复购，复购率从 18% 提升至 31%，贡献营收 +180 万

## 选词避坑

- **职能匹配**：技术岗多用 3/6 类（搭建、开发、重构、优化、提速），管理岗多用 1/4 类（带领、统筹、谈判、推动），运营/市场岗多用 5/7 类（运营、拉新、转化、增长）。
- **不夸张**：协调 ≠ 统帅，支持 ≠ 主导。动词强度要与真实角色相符，背调会戳破夸大。
- **一句一动词**：一条 bullet 一个主动词开头即可，别叠"主导并统筹并推动"。
- **时态/语言统一**：英文简历过往经历用过去式（led, built, optimized），现任用现在式；全篇统一。
