## 这是什么

书的全部内容都是关于 **Agent Skills**(智能体技能,Agent Skills 开放标准)。因此本项目把"产品"落地为**面向该标准的技能候选包**——这是与书最契合、但不能据此推断可盈利的形态。

每个技能包都按书第 6 章工程流程(需求→设计→实现→测试→发布)开发,严格遵循:
- description 极简公式(功能 + 触发场景 + 反向触发词)
- SKILL.md 正文克制(≤500 行),重型内容拆 `references/` 按需加载
- 三种类型设计(约束型 / 模板型 / 流程型)
- 禁止清单 + 踩坑点 + 安全约束
- 评测题库(`tests/`,与 SKILL.md 分离)+ 发布前检查清单

## 3 个产品速览

### 01 · 小红书爆款文案 `xhs-hit-copywriter`
- **做什么**:一段素材 → 有真人感、不像 AI、带钩子的爆款笔记(标题+正文+emoji+标签)。
- **技能装的经验**:爆款标题公式、口语化语气库、违禁/限流词表、去 AI 味禁止清单。
- **上架**:扣子技能商店 / ClawHub　**变现**:付费技能 / 私域引流。

### 02 · 数据分析报告 `data-report-pro`
- **做什么**:Excel/CSV → 三阶段专业分析 → 可脱机打开的精美 HTML 可视化报告。
- **技能装的经验**:三阶段分析法、so-what 哲学、图表选择指南、报告模板 + 设计简报(给方向不给参数)。
- **附**:可渲染 HTML 模板、可解析 CSV 测试样本。
- **上架**:ClawHub / GitHub　**变现**:B 端订阅 / 企业内部市场。

### 03 · 简历 STAR 优化 `resume-star-optimizer`
- **做什么**:流水账经历 → STAR 拆解 + 量化追问 + 强动词 + ATS 对齐 → 成果型 bullet。
- **技能装的经验**:STAR 模型、量化追问清单、强动词库、ATS 关键词对齐、不编造红线。
- **特色**:量化追问设为强制人工确认点,缺数据则标注待补、绝不编造(书"可容错"标杆)。
- **上架**:扣子 / ClawHub　**变现**:商店付费 / 单次润色。

## 审核结论

3 个技能包对照书中 9 项标准 + 结构/HTML/CSV 可解析校验,**历史结构检查 PASS；不代表当前平台准入、实际效果或商业验收通过**。两处静态扫描疑点经严格校验确认为误报。详见 `_review/审核报告.md`。

每个技能包内含 `PUBLISH-CHECKLIST.md`,列明各平台(扣子可视化部署 / `clawhub publish` / GitHub clone)的发布要点。
